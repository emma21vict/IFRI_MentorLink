# CONSIGNES POUR L'ÉQUIPE - IFRI_MentorLink

## Règles d'or
1. Toujours faire **Pull** avant de commencer à travailler
2. Toujours faire **Pull** avant de faire **Push**
3. Messages de commit : clairs et précis

## Organisation du projet
- `src/` : code source
- `docs/` : documents
- `README.md` : présentation du projet

## Éviter les conflits
- Communiquer sur qui fait quoi
- Ne pas travailler sur le même fichier en même temps
- En cas de doute : demander à l'équipe

## Commandes GitHub Desktop
| Action | Bouton |
|--------|--------|
|Récupérer les modifs|Fetch origin → Pull|
|Envoyer ses modifs|Push origin|
